## 可用行情

仓库当前有两份 563360 一分钟历史样例，可离线查看：

- `data/market-history/563360_1m_20261030.json`：2026-10-30 全天，242 条。

它们不是回测 CLI 的自动输入。CLI 从 SQLite 历史缓存读取，缺失时连接 AmazingData。技术回放 API 可接收分钟线 bars，但还需要信号提供器、数量解析器、成本模型和完整账户上下文。样例区间很短；即使完成回放，也不能据此宣称 V1.0 通过长期稳健性或认证检验。

## 执行前必须补齐

1. **账户与持仓基础**：现金、持仓数量、持仓成本价已提供。仍需提供回测账户时点的 563360 可卖数量、保护底仓及持仓市值，并注明数据来源和时间。
2. **V1 完整配置与认证门槛**：需提供 `load_intraday_v1_config` 所需全部参数分组、证券交易规则和来源时间，以及最低收益、配对交易净利、最大回撤、样本量、成本压力、参数扰动和 walk-forward 等门槛。不能自行补默认值。
3. **数量与流动性解析**：需明确单笔资金、仓位、流动性及 T+1 约束如何换算为整手数量，并提供 V1 回放所需的 `CandidateQuantityResolver` 规则。
4. **历史区间及保存授权**：现有本地样例仅覆盖 2026-10-30 全天及 2026-11-02 截至 11:28。若需扩展历史，需确认 AmazingData 连接和历史数据服务条款允许本地保存行情和回测快照；确认后才能启用 CLI 的持久化确认参数。
5. **回测账户时点**：当前只记录了账户金额、持仓和成本价，没有说明这些数值对应的历史日期/时间。需确认账户快照时间与所选回放区间匹配；模拟器要求账户快照不晚于首根历史 bar。

## 佣金实现回归记录

- 佣金口径：比例佣金按成交额乘以 0.5 bps；单笔最低 0.1 元按每个模拟 fill 独立应用，买入和卖出均适用。部分成交每一笔分别计算最低佣金。
- 实现位置：基础价格触发回测 `run_backtest`、日内回放 `run_intraday_backtest`；CLI 提供 `--minimum-commission` 参数，默认 0（禁用最低佣金），费用参数随回测结果持久化。
- 测试命令：`uv run pytest -q tests/test_intraday_backtest.py tests/test_backtest_cli.py`。
- 结果：12 项通过；覆盖日内部分成交逐笔最低佣金、CLI 参数持久化，以及两套回测路径既有行为。
- 静态检查：相关 Python 源码及测试的 Ruff 检查通过；回测、日内回放和 CLI 源文件的 mypy 检查通过。
- 限定：以上仅验证佣金模型和回测工具路径，不代表使用 563360 的账户/行情执行了策略回测，也不代表 V1 认证通过。

## 当前实现的边界

- `python -m a500_t_trader backtest` 是简单价格触发回测，要求显式 `buy_below` / `sell_above` 规则；它不是 V1.0 策略执行器。
- V1 分析/模拟 API 要求调用方提供数量解析器；最低佣金通过执行参数显式设置。
- 回测认证接口只评估调用方提供的证据和配置；它不会生成完整 V1 策略回测，也不会推定认证阈值。
- 所有模拟成交均非实际成交；历史认证不是未来收益保证，也不是下单授权。

补齐上述账户、策略配置、数量规则和数据保存授权后，才可执行 563360 历史回放；之后记录实际数据区间、行情快照指纹、参数、费用和结果。
