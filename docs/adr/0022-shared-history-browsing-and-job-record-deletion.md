# 共享日线行情独立于下载任务查询

状态：已采纳

当前 `/data/history` 页面仅跟踪按认证主体隔离的历史行情下载任务；下载得到的日线数据及其覆盖范围属于共享历史行情存储，但目前没有对应的 HTTP 读取 API。新增受认证保护的共享日线查询，按单个证券代码和包含起止日期的范围读取并分页；不把日线数据关联到下载任务，也不复用创建任务的操作来查询。页面默认不选证券代码，日期范围为过去一年至昨天；用户显式查询后才加载数据。按交易日从早到晚展示实际观测到的记录，包括日期、开盘价、最高价、最低价、收盘价和成交量；有值时显示成交额。日期范围未完整覆盖时明确提示覆盖不完整；范围已完整覆盖但没有记录时明确提示无行情。不补造缺失交易日。表格支持上一页／下一页，默认每页 20 条，并可选每页 10、20 或 50 条。任务记录区默认折叠，支持按需加载当前主体的全部任务。用户确认后可删除其任务记录；删除仅移除任务记录，不删除可能被多个任务复用的共享日线数据及覆盖范围。本决策取代 ADR-0020 中“不新增共享历史行情 HTTP 读取 API”的决定；下载任务仍只记录状态和进度，不持有专属行情结果快照。
